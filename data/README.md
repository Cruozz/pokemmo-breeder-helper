# Species data

`guide.json.gz` is a separate read-only snapshot for the native Pokédex, horde,
and EV pages. It does not replace any planning, OCR or breeding data. Built by
`scripts/build_guide_data.py` from the public factual data at
https://tool.lzpoke.com/data/monsters.json on 2026-09-29; source hash and collection
time are embedded. Species are limited to national IDs 1–649. Source season and
time conditions are retained; unknown mechanics are not inferred. This snapshot
is third-party reference data, not an official or real-time game database.

`species.json` is generated by `scripts/build_species_data.py` from the public
CSV data in [PokeAPI/pokeapi](https://github.com/PokeAPI/pokeapi). The bundled
scope is National Pokédex species 1–649, matching the generations currently
used by this tool. PokeMMO-specific differences should be kept as explicit,
reviewable overrides instead of being read from game memory.

Additional bundled files:

- `moves.json`: PokeAPI generation 1–5 move names used as an OCR dictionary.
- `abilities.json`: PokeAPI normal and hidden ability names for species 1–649,
  used for OCR normalization, autocomplete and the hidden-ability planning flag.
- `locations.json`: 4,441 normalized rows imported from the user-provided
  `全地区精灵分布.xlsx`; all rows resolve to an internal species ID.
- `egg_moves.json`: 11,145 normalized chain rows imported from the
  user-provided `技能遗传链.xlsx`; all rows resolve to an internal species ID.
- `pokemmo_overrides.json`: reviewed PokeMMO/legacy Chinese species aliases and
  explicit game-specific breeding differences such as the Nidoran family.
- `move_ocr_overrides.json`: reviewed OCR mistakes from supplied screenshots.

The generated JSON metadata records each source workbook name, modified time
and SHA-256 digest. No PokeMMO process, client file, log or network traffic is
used to produce any of these files.
`market_catalog.json.gz`：2026-10-12 采集的市场名称与分类资料，包含 2969 个道具和 649 个宝可梦的族群／蛋组／分级信息。仅包含查询用元数据，不内置固定市场价格；文件内保留公开来源与原文件 SHA-256。可使用 `scripts/build_market_catalog.py --input-dir <下载资料目录>` 重建。
