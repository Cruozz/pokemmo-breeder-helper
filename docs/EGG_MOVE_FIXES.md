# 遗传技能修复记录 · 2026-09-15

## 当前状态

本轮修复基于仓库提交 `c61a13f`，纳入 Windows V0.2.5 发布；构建验收与发布约定见 `DESKTOP_025_NOTES.md`、`release.ps1` 和 `AGENTS.md`。
本次范围是 **Windows 桌面端 + 共享 Python 规划器**；安卓界面仍未接入遗传技能选择。

## 修复内容

### 1. 技能校验与资料解析

- 按实际孵出物种校验可遗传技能，进化形态查询回退到对应孵出形态。
- 中英文名称归一化、重复项去重，最多选择 4 个不同技能。
- 规划入口不进行模糊猜测；不在内置蛋招式资料中的技能会明确报错。
- 将完整资料链解析为有序物种节点和学习方式注释，保留幼年、蛋、等级、BP、写生等信息。
- 已验证 **11,145 条**内置资料链全部解析成功，没有丢行。

### 2. 每一代都检查能否保留技能

旧逻辑直接合并双方技能，可能使不合法技能穿过中间物种。现在只保留该子代实际可遗传的所选招式。
同蛋组只证明可以配对，不证明能遗传所有技能；百变怪也不能把错误录入的招式注入后代。
例如图图犬会写生，不代表图图犬的子代可以通过孵化继承任意写生招式。

### 3. 技能导入是真实孵化步骤

- 新增不提升有效 IV 档位的准备步骤，覆盖 0V + 0V、1V + 1V、多技能逐次导入等情况。
- 可以复用库存中尚未携带目标技能的 0V 中间母体，跨蛋组接力传递。
- 所有步骤都记录父母 ID、实际性别、道具、技能状态及核销依赖，不会重复消耗同一只素材。
- 沿用高价值素材保护，以及性格、头目、梦特与性别约束。

已验证的库存例子：最终母体 HP=31，其余三只不要求 IV，源头已学会“污泥攻击”。

1. 无壳海兔♀ + 溶食兽♂ → 携带污泥攻击的无壳海兔♂。
2. 水跃鱼♀ + 上一步无壳海兔♂ → 携带污泥攻击的水跃鱼♂。
3. 妙蛙种子♀ + 上一步水跃鱼♂ → 携带污泥攻击的妙蛙种子♀。

结果为 **3 次孵化、0 次补购、1 个 HP 护腕**；前两个中间代锁公，最后保留目标母体性别。

### 4. 高 IV 和补购

- 母体主线搜索保留满足技能约束的状态，避免被更便宜但没有技能的普通分支挤掉。
- 6 项 IV 规划保留真实库存的技能组合，并裁剪在现有“采购只数”成本模型下被完整技能组合覆盖的虚拟素材，避免组合爆炸。
- 已完成 IV 的母体缺技能时，会比较 N V 母体 + N−1 V 技能父本的直接导入方案。
- 补购清单明确列出“必须已携带技能”和梦特潜力要求，不能仅凭物种名称购买。
- 资料源头是火焰鸡等进化形态时，不再悄悄换成未准备技能的火稚鸡。
- 支持明确购买已经准备好的同进化线多技能素材；这是采购规格，不是已经查询到的交易行现货。
- 若候选可以直接购买满足条件的精灵，报告明确写“尚不在库存”，不会称作已有库存。

### 5. 桌面交互与来源展示

- 显示已选数量；超过 4 个时禁用确认，支持清空和取消。
- 资料文本只读并可滚动，明确区分“资料候选链”和“本次执行路线”。
- 界面来源摘要和报告中的逐代路线来自真实选中的动作树，不再显示与父本无关的最短资料链。
- 路线树中的技能携带者和导入节点使用归一化后的真实规划状态。

## 仍需明确的边界

1. 遗传资料来自仓库现有工作簿，不是实时查询游戏数据；不确定的物种/技能不被自动视为合法。
2. 只规划已确认携带的所选蛋招式。等级学习、BP 教学、写生，以及必须在中间代重新学习的步骤，仍需在游戏中手工完成并确认库存；本轮没有把教学费用/升级时间纳入模型。
3. 技能准备搜索是有界启发式：最多 8 轮扩展、256 个派生候选，每种机械状态保留 4 条备选。没有找到方案不等于证明无解，也不承诺所有复杂库存下全局最优。
4. 采购优化沿用采购只数/孵化次数等指标，没有读取交易行价格，也不保证已存在相应现货。
5. 熏香占用道具位等原先未安全建模的情形仍保持原有保护，不会为了生成路线而绕过限制。
6. 未更改库存数据库格式，未操作真实游戏或真实库存；真实游戏截图 OCR 实测和安卓界面接入不在本轮范围；Windows EXE 的合成图 OCR 自检由发布脚本执行。

## 主要文件

- `reference_data.py`：输入归一化、严格校验、资料链解析与可遗传招式查询。
- `chain_planner.py`：逐代技能约束、准备步骤、高 IV 搜索、采购规格与真实来源报告。
- `planner.py`：公开规划入口的技能校验和直接父本解析。
- `app.py`：选择窗口、实际来源摘要与路线树标识。
- `tests/test_egg_moves.py`、`tests/test_egg_move_picker.py`：专项回归。
- `scripts/egg_move_smoke.py`：隔离界面手动检查入口。
