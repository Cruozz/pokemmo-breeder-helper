# Windows 0.2.45

- 修复精灵名字混入属性缩写、相邻文字片段漏拼以及名字残缺后仍被确认入库的问题。
- 增加已核对的“安飘虫→安瓢虫”修正，并处理飞／岩／地／幽／普／斗等属性缩写。
- 单只详情名字无法可靠匹配时，只对名字行进行两次放大重读；等级相符且两次完整种类一致才接受。正常名字不额外重读。
- 只剩“拉”等片段时保留原文、提示补全，不根据恶冰属性猜测为狃拉或玛狃拉。连续录入必须先选出图鉴中的完整名字，才可确认入库。
- 已有错名记录可手动编辑或重新识别。本次仅更新 Windows，Android 保持 0.10.0，孵蛋规则保持 0.2.43。
- 批量截图录入仅作可行性评估，本版本未增加批量放生列表导入功能。程序不操作游戏或确认放生。

验证：Python 完整回归 693 项、1,440 项子测试全部通过，名字相关专项检查 100 项通过；99 个 Python 文件语法检查及 git diff --check 通过。实际 Windows EXE 通过自检，包括安瓢虫误字修正、残缺名字拒绝和粒子边界识别。本地截图试验读取 20 条规范名字、完整 IV 与性别，仓库等级逐格核对 20/20，并读取 11 个可见梦特标记；模拟首次漏读名字前缀后，实际 OCR 的两次局部重读恢复为玛狃拉。
