# 电脑端 V0.2.5：遗传技能规划与发布自检

## 用户可见变化
- 按孵出物种逐代检查技能，拒绝非法技能，统一中英文技能名并限制最多 4 个。
- 支持不升 IV 的导入、多技能合并、库存跨蛋组遗传链及已有高 IV 母体补技能。
- 修复 5V/6V 四技能路线的候选裁剪和性能问题。
- 补购清单标明必须携带的技能及梦特要求，来源显示与真实执行路线一致。
- 技能选择窗口支持计数、超限禁用、清空和只读滚动资料。

## 发布保障
- release.ps1 从 APP_VERSION 读取版本，并核对 Windows 文件版本。
- ZIP 生成前必须运行刚生成的 EXE 自检：Tk/图标、649 个物种、11,145 条资料链、遗传技能执行计划、真实 ONNX OCR 推理。
- 发布包包含使用说明、第三方声明、EXE 校验和与 self-test.json。
- 后续源码更新默认须测试、打包、提交源码并上传 GitHub Release；详见 AGENTS.md。

## 使用边界
- 教学、升级、写生等仍需手工准备；程序不会操作游戏，也不查询交易行现货或价格。
- 未改动库存存档格式。旧执行计划不会自动替换，建议人工核对库存后重新生成并确认新计划。
- 安卓界面暂未接入技能选择；本次是 Windows 桌面版本。
