# Windows V0.2.26：完整素材保护

## 规则

目标某项 IV 设为 X 时，只要库存素材在该项有 31，就整只排除出本次规划。
例如目标为 HP／防御／特攻／特防／速度 5V 内敛耿鬼，以下库存素材均保留：

- HP／攻击 2V 耿鬼。
- 攻击／速度 2V 百变怪。
- 带攻击 V 的不定形组素材、母体与性格手。

不再把实际多 V 素材去掉不需要的 V，按少 V 参与孵化。任何 X 项适用相同保护；6V 目标没有 X 项，仍可正常使用 6V 库存。
这是一项素材保护规则，库存记录及实际 IV 不修改。以后规划需要攻击 V 的目标时，保留的素材可以重新参加；X 项本身仍表示子代该项不要求固定值。

## 覆盖范围

保护在库存进入搜索前执行，覆盖母体、百变怪转母、同蛋组支线、性格手、遗传技能来源、自动重算和不同规划策略。
目标性格、梦特、遗传技能或“允许使用百变怪”均不会绕过保护。
规划报告显示目标 X 项与本次自动保护数量；手动“本轮禁用”继续独立累积。
原有保性格升 V 转母例外仍可用，前提是双方库存素材均不含目标 X 项上的 V。

## 使用

更新后重新生成规划，并确认启用新路线。旧执行步骤及已完成进度保留，不会自动改写或核销。
保护素材后，可用库存可能减少，路线可能需要更多采购；规划器会比较剩余库存与采购路线。
本次发布 Windows EXE、ZIP 和 SHA256SUMS.txt。安卓共享源码规则标记为 0.2.26，已发布的安卓 0.5.1 APK 未包含本次修正。

## 验证

464 项 Python 测试通过。覆盖截图配对、各项 X 保护、不同规划策略和百变怪设置、性格与梦特、六 V 目标、切换到攻击目标后的重新使用，以及库存记录保留。
实际 Windows EXE 自检验证截图素材不参与攻击 X 的目标，且可重新参加要求攻击 V 的目标。发布资产附带 SHA-256 校验。
