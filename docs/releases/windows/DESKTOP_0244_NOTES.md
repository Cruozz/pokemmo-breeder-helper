# Windows 0.2.44

- 修复普通精灵被误判为蝙蝠、幽灵等粒子，以及右下角真实粒子图标漏识别的问题。
- 识别区域限定为精灵详情立绘区右下角、与等级名字同行的图标槽；通过面板边框和文字大小适配位置与缩放，排除模型、背景动画、性别符号、下方属性和相邻面板。
- 匹配同时检查尺寸、完整轮廓、透明背景和最佳候选差距。弱匹配不再自动标为“带粒子”；看不清或多粒子时可手动补选。
- 已有误标记录请在库存编辑中取消“带粒子”并保存。自动识别修复不会批量覆盖已有粒子登记。
- 本次只更新 Windows；Android 保持 0.10.0。
- 孵蛋规则保持 0.2.43，已有路线可继续使用。Windows ZIP 仅包含根目录下的一个 EXE。
