# Windows V0.2.13：库存重新排列与账号拖拽排序

旧仓位重新录入素材后，记录会追加到库存末尾。现在可点击“重新排列”，先按自定义账号顺序分组，再按仓库页、行、列的数字顺序归位。例如 OneBit 的 1-1,10 会排在 OneBit 的 1-1,9 后面，不会混入 TwoBit 的同一仓位。

## 使用

- 在“素材库存”的账号筛选旁点击“账号排序”，上下拖动账号，点击“保存并重新排列”。扫描、录入和库存筛选中的账号下拉列表同步更新。
- 也可选中账号使用“上移／下移”或 Alt+上／下；较长列表支持滚动和拖动到边缘自动滚动。“主账号”和没有素材的账号也能调整位置。
- 账号顺序和已排列结果跨重启保留。取消或按 Esc 放弃本次拖动。
- 新录入素材仍追加到末尾，需要时再次点击“重新排列”。该按钮排列全部库存并保留当前搜索、筛选和仍可见的选中项。
- 未定位或位置无效的素材排在所属账号末尾；相同仓位的多条记录全部保留，不合并、不删除。

## 数据与规则

排序单独保存账号顺序和素材 ID 显示顺序，不改写库存记录，不修改账号、仓位、素材属性或时间戳。规划器仍接收原始库存顺序，孵蛋算法、核销与遗传规则保持原样。

## 验证

- 338 项 Python 回归测试通过，包含新增的 9 项排序与实际 Tk 控件测试。
- 覆盖跨账号同仓位、数字页格、空位置、同位置多记录、手动归位、新素材追加、取消、保存失败、长账号列表边缘滚动，以及重启保留。
- 实际主窗口检查 700、880、1460 像素宽度及账号排序弹窗；使用合成素材和临时库存。
- 发布脚本检查版本、执行单文件 EXE 自检并生成 ZIP、SHA-256。EXE 自检包含库存排列、Tk、OCR、离线资料及现有孵蛋规则校验。
