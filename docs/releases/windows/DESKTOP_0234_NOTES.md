# Windows V0.2.34

## 母体升 V 与遗传技能

- 目标母系可以在升级过程中分别获得技能，支持将“传技能”和“升 V”合在同一次孵化中；技能、IV、性格支线可采用其他兼容蛋组物种。
- 已有目标母体或库存公体转出的母体时，不再把“补购同种、已经带齐所有技能的精灵”当默认捷径。这类现成采购只有明确手动报价后才参与备选比较。
- 技能已经进入目标母系后可随后续配种继续传递，后续普通 IV 父本和性格手不需要重复带齐技能。仍逐次检查子代能否遗传该招式，百变怪不能凭空提供技能。
- 技能父本自己的升级招式单独判断：双方已会且子代可通过升级学习时，或与百变怪繁殖的非百变怪亲本已会时，可以直接传下；否则才规划重新学习，写生和教学能力不会直接当成出生时已会。
- 同档补技能仍可用于已满目标 IV 的母体；不会为准备技能而替换掉母体已经建立的目标 IV。升档方案继续检查各项 IV 的重叠和护腕分配。
- 新增有明确资料依据的技能准备动作。例如六尾支线升 V 后，可在配种前学习神通力。升级学习／回忆、写生、BP 教学分别标明；仅有“蛋”注释的中间物种不会被当成可直接学习。
- 准备动作保存到规划和执行快照，导图与文字版显示技能及准备要求，核销确认明确提示必须已经完成准备。不会提前修改库存精灵的技能，也不会把需要学习的招式当成子代出生时已经继承。
- 技能准备列为独立待报价项目，可在“成本与报价 → 素材估值”中填入费用；确认无新增支出时可手动填 0。同等采购数量、步骤及库存利用条件下比较报价，缺价保持待报价。

技能传递规则参考 [PokeMMO 论坛繁殖指南](https://forums.pokemmo.com/index.php?/topic/132652-the-ultimate-breeding-guide/)。升级、写生等具体来源使用工具内置的技能遗传链资料，规划中的采购项是需求条件，仍需核对所购精灵及实际技能。

## 性格处理

- 新规划在母体达到全部目标 IV 后才确认随机性格。例如 5V 索罗亚先完成双技能母体，命中胆小即可结束；未命中后保留母体，再制作同蛋组性格手。
- 已有合适性格素材仍可直接利用。性格手沿原有分阶段流程制作、确认和保底，收尾时验证性别、IV、头目属性及不变之石分配，不要求性格手也是目标物种或重复携带遗传技能。
- 旧执行路线保留其原有性格提示阈值，重新生成规划后采用新规则。
