# Windows 0.2.47

- “扫描素材”分为连续识别（逐只）和批量识别（整批），分别保留范围、仓位与结果；切换时暂停另一种采集。
- 新增同页连续 1～20 只的批量读取：分别框选仓库完整网格与放生确认名单，提取名字、六项 IV、性别、等级和可见梦特蓝钻。
- 数量或可见高亮范围不一致时不分配仓位；缺失资料和等级不符须核对。同名同等级分别保留，绿色星标与邻列精灵图标不作为梦特蓝钻。
- 提供整批审核表、原图对照、名字候选和逐项审核。性格、头目、粒子、时装未显示时保留待核对；支持对所选项目明确填写状态。
- 草稿单独存于本机，确认后才进入库存；导入不覆盖已占仓位，同批重试不重复写入。
- 只读取画面，不操作游戏。读取名单后在游戏点击“否”返回。使用步骤见仓库 docs/bulk-capture.md。
- 本次仅发布 Windows，Android 保持 0.10.0，孵蛋规则保持 0.2.43。

验证：完整回归 740 项、1,440 项子测试全部通过，124 个 Python 文件语法检查及 git diff --check 通过。实际 EXE 自检验证批量界面、本机草稿、未知字段拦截和数量不符时不分配仓位；ZIP 仅含根目录单个 EXE。提供的两组各 20 只截图在 75%、100%、125% 尺寸下，名字、IV、性别、等级与可见梦特标记均一致；整张窗口混入背景详情时被范围检查拒绝。
