# Windows V0.2.25：随机性格转母的素材保护

## 修正

- 随机性格转母使用同档位百变怪，拦截截图中的爽朗 2V 公美纳斯＋认真 3V 百变怪、无不变石、孵出随机性格 3V 母丑丑鱼的路线。
- 保留此前确认的保性格升 V 例外：目标性格 2V 公体携带不变之石，匹配 3V 百变怪携带新增 IV 的护腕，可升到目标性格 3V 母体。
- 继续要求子代保留原素材有效 IV，且不低于双方档位；3V 公体＋2V 百变怪转母仍排除。每只父母最多携带一个道具。
- 同档位转母、同档位双护腕升 V，以及不转性别的普通升 V 保持可用。保护规则由共同子代构造入口执行，覆盖母体预转换及其他搜索路线。

这是规划器的素材使用策略，不表示游戏禁止不同档位精灵配对。

## 本轮禁用

本轮禁用按点选的单只库存素材累积排除；规划器此前可能换用另一只同档位百变怪，所以连续禁用不能代替配对策略。
验证连续三次禁用、重算及美纳斯／丑丑鱼同进化线切换后，三只素材均保持排除。

## 更新使用

更新后重新生成规划，再确认启用新路线。已经保存的执行步骤保留，不会自动改写或核销。
没有合适的同档位转母组合时，会比较其他库存母体或采购路线，不使用随机性格 2V＋3V 转母作为兜底。
本次发布 Windows EXE、ZIP 和 SHA256SUMS.txt；安卓共享源码的规则标记更新为 0.2.25，已发布的安卓 0.5.1 APK 未包含本次修正。

## 验证

455 项 Python 测试通过，覆盖美纳斯 5V 头目目标、不同规划策略与百变怪开关、保性格转母例外，以及连续禁用的累积保留。
Windows 发布包执行实际 EXE 自检，验证截图配对被拦截及保性格升 V 转母仍可生成；发布资产提供 SHA-256 校验。
