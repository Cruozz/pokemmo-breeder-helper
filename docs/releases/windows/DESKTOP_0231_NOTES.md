# Windows V0.2.31

## 界面与计算

- “计算策略”只保留在“成本与报价”旁。原两处绑定同一个设置，没有两套算法冲突；现在消除重复入口。
- 规划改用本机独立进程，降低计算进程优先级，避免大量 Python 计算占用界面线程的执行机会。
- 计算中显示已用时间，提供“取消计算”。取消、清除路线和关闭窗口会终止自己启动的规划进程；迟到结果不能覆盖当前路线。
- 相同库存、目标、约束与报价的成功结果最多复用 60 秒；报价已过期时重新计算。
- 为素材建立查询索引，缓存固定性别资料，提前排除没有可用母体种子的精确子问题。完整素材保护、百变怪转换、性格、头目、梦特和技能约束继续参与搜索。
- 复杂库存的省钱规划仍可能需要较长时间；计算期间可以操作窗口、切换页面或取消。

## 打开与关闭

- 仍分发一个 EXE。首次运行准备所需组件并显示进度；后续打开复用已校验的本机运行目录。
- 运行缓存位于 `%LOCALAPPDATA%\PokeMMO-Breeder-Helper\runtime`，按版本和内容哈希隔离，占用额外磁盘空间；删除后会重新准备。缓存不包含库存或登录信息。
- 首次准备可取消；重复启动通过本机互斥锁避免同时写入同一个运行目录。
- 关闭主窗口时先保存窗口状态并隐藏窗口，攻略阅读组件在后台收尾，减少关闭等待。
- 规划输入与输出只在本机临时目录间传递，结束后清理；不会上传库存。
