# Windows 0.2.43 / Android 0.10.0

- 42 种图标的离线粒子库：40 普通粒子与 2 特殊身份标记；中英文名称、别名、图标来源见 docs/particles.md。识别仅填写面板可见粒子，多粒子由用户主动补选。
- 粒子默认保护，支持指定多目标、无视和同种限一次。严格模式检查实际全部粒子，后代携带不重复计数，低 V 粒子支持先接入再升 V。
- 库存手动标记五家族时装；时装目标沿原后代母系到成品，公体可百变怪转母，关闭本次 X 位 31 保护。执行、JSON、性格阶段与重算保留母系和粒子。
- 手机局部重读缺失名字与 IV；稳定但不完整的实时结果转待审核并保留截图与仓位。改用懒加载编辑表单、减少主线程图像处理及重复草稿读取，编辑时暂停采集。
- 不完整结果禁用直接入库。修改父母的粒子或时装后，旧路线必须重算才可核销。
- 共用规则 0.2.43；安卓 versionCode 18。旧规则路线为备忘，已完成子代保留，新生成路线采用新规则。

升级前可导出 JSON 备份；APK 覆盖安装保留数据，请勿卸载旧版。Windows ZIP 根目录仅一个 EXE。
