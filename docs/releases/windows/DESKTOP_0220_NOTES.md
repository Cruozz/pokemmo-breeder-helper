# Windows V0.2.20 — 努力值仅列纯点群怪

原努力值页按每条群怪记录展示，没有检查同一地点是否会出现其他群怪，且重复列出同一种精灵。
本版只显示纯点群怪，每种精灵合并为一行并标记“纯点”。

纯点使用完整群怪资料判断：同一地区、地点（含资料中的楼层或区段）和遭遇方式只有一种精灵。
草地、水面等方式分别判断；普通单遇不会影响群怪纯点。
只要其他季节、时段或群怪数量存在另一种群怪，该点也会被排除；同样努力项的不同精灵仍算混点。
精灵本身同时提供多项努力值时不纳入努力值纯点列表。
判定先于关键词、地区、季节、时段、群怪数量和努力项筛选，筛选不会把混点变成纯点。

列表显示精灵、纯点标记、单只基础值、分布地区、地点数和群怪数量。
选中后集中展示匹配的纯点地点、方式、等级、季节、时段及对应数量的整群基础收益。
整群基础收益不含强制锻炼器、活动或其他加成。
当前资料符合上述条件的精灵共 31 种；防御项暂时没有符合条件的记录，因此显示空结果。
地点判定基于包内群怪资料；资料未覆盖的实际游戏变化仍需以游戏内图鉴为准。
