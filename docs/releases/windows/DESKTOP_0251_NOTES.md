# Windows 0.2.51

- 修复蓝色选中边框干扰批量性别识别：单独检查格位左下角的公母符号及圆环形状，解决粉色母符号被读成公或未识别。
- 修复名单名字旁蓝钻漏识别：蓝钻尺寸独立于文字高度判断，检查当前列内的颜色、尺寸和下端收尖形状，排除绿星、方块和邻列图案。
- 同批截图与范围不变时，“重新识别这一批”可校正已入库、未审核记录的性别与漏记梦特。保留同一库存编号与手填性格、粒子、时装等其他资料，修改前本机备份，不重复录入或恢复已离库素材。已审核、身份或仓位变更的记录不自动修改。
- 保留批量直接入库、未审核素材可用、补充资料可留空、指定仓位与新批次接续。
- 仅发布 Windows；Android 保持 0.10.0，孵蛋规则保持 0.2.43。
