# Windows V0.2.21 — 努力值修正与窗口位置记忆

## 努力值纯点

上一版把纯点限制为全年、全天只有一种群怪，导致遗漏很多训练点，防御项甚至为空。
本版参考 [努力值检索页面](https://tool.lzpoke.com/search/encounter-search?season=1&mode=ev) 的努力项纯点规则修正：

- 对同一地点与遭遇方式，按具体游戏季节、时段检查完整群怪池。
- 同点可以有不同精灵，只要所有群怪均只提供同一项努力值，即为努力值纯点。
- 某季节或时段出现其他努力项时，只排除那些条件；详情明确显示其余可用的季节、时段。
- 混合努力项不能通过精灵名、努力项或三只／五只筛选变成纯点；群怪数量不改变遭遇池判断。
- 按资料中的地点编号区分同名楼层或区段；草地、水面等遭遇方式分别判断，普通单遇不计入群怪池。
- 每只精灵只显示一行并标记纯点，选中后汇总地点、季节、时段、数量和整群基础收益。

包内资料按全部地区、季节、时段和群怪数量查询，符合条件的精灵数为：

| 努力项 | 精灵数 |
| --- | ---: |
| HP | 39 |
| 攻击 | 62 |
| 防御 | 39 |
| 特攻 | 36 |
| 特防 | 18 |
| 速度 | 57 |

恢复了小拳石、隆隆石、大岩蛇等防御点，以及 214 号道路的麒麟奇等限定条件点。
软件展示资料内全部符合条件的群怪点；参考网站努力值页还限定附近有回复点，因此结果数量可能不同。
游戏季节以游戏内为准。整群基础收益为单只收益乘群怪数量，不含加成；资料沿用现有公开遭遇快照。

## 窗口位置记忆

- 正常关闭主窗口时保存最后的位置和大小，下次启动自动恢复。
- 最大化关闭后仍以最大化打开，还原窗口时保留之前的位置和大小。
- 最小化关闭不保存最小化后的隐藏坐标，也不在下次启动时自动最小化。
- 支持副屏上的负坐标；原显示器移除后把窗口调整到当前可见屏幕。
- 设置写入用户数据目录的 `window_state.json`；首次打开或配置无效时使用默认窗口。

版本号、使用说明和 Windows 文件信息同步更新；发布包包含实际 EXE 自检结果。
