# Windows V0.2.33

## 文字孵蛋路线

- 路线区域新增“思维导图 / 文字步骤”切换，主窗口和“独立查看路线”窗口均支持。
- 文字版按依赖关系分阶段，保留原规划的步骤编号，每步列出亲本 A、亲本 B 和得到的子代。中间亲本标记来源步骤。
- 精灵行保留图片、名字、对应六项个体值及本步携带的锁定道具；公用蓝底、母用粉底，无性别或未锁性别用灰底，同时保留性别符号或文字。
- 本步护腕、不变之石显示在对应亲本上，子代行不会误显示下一次孵蛋的道具。文字版不显示账号、位置、费用和说明段落。
- 单击步骤后，可用上方原有的完成、核销和孵化中按钮操作；新建议继续只读预览。视图切换不修改规划、库存、计算策略和执行进度。
- 导图中折叠的已完成来源仍保留在文字版历史中；阶段只统计实际规划步骤，后续性格合成示意不会被当作可执行步骤。
- 文字版随窗口宽度排列，使用纵向滚动条、滚轮及方向键、Page Up/Down、Home/End 浏览。按当前可见卡片绘制，切回导图保留缩放和滚动位置。

## 下载
