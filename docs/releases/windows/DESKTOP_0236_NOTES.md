# Windows V0.2.36

## 首次启动与运行缓存

- 修复旧启动器解压完成后必须把 `.prepare-…` 改名为正式运行目录的问题。Windows 上，文件夹被持有且不允许删除共享时，这一步可能出现“对路径的访问被拒绝”。新版完成组件校验后直接使用原目录，并保存相对目录指针供后续启动复用。
- 损坏或不完整缓存会重新准备到独立目录，不覆盖或移动可能仍在使用的旧目录。校验未完成的目录不会被当作可启动程序。
- 默认运行缓存无法创建时，尝试当前用户临时目录下的独立缓存。仅运行组件使用备用目录，库存、执行规划及账号设置的存储口径保持不变。
- 启动失败弹窗显示具体阶段，并将异常详情写入可写运行缓存中的 `startup.log`。可把提示和日志发给作者定位；截图本身不足以区分权限不足、进程占用及安全软件拦截。
- 原来默认版本缓存仍可识别；新缓存指针会验证范围、完整性标记和核心程序哈希。不会通过指针选择缓存根目录以外的路径。

## 验证与发布

- 新增编译后启动器的隔离测试：首次准备与复用、真实 Windows 目录改名被拒绝、损坏缓存、非法指针、备用缓存、取消清理以及失败日志。
- 本次不清理或迁移真实库存；取消时只清理本次未完成的运行组件目录。
- Windows ZIP 仍只包含根目录下的 `Pokemmo孵蛋助手.exe`，仅发布 GitHub。
