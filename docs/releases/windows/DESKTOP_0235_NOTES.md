# Windows V0.2.35

## 库存与遗传技能

- 保留库存亲本真实形态，以进化家族判断繁殖关系；子代使用实际孵出物种。技能学习资料来自内置的 PokeMMO 图鉴，分别核验每个形态，不把整条进化线视为共享技能。
- 支持母九尾等辅助母体先孵出同家族公体，组合遗传技能与 IV 后接入目标母系。升级／回忆等准备在实际使用该亲本前列出，学习费用单独待报价；不会把母亲会的所有技能当成子代出生就会。
- 目标攻击为 X 时，攻击带 V 的库存继续受完整素材保护。没有新增库存未入选原因界面。

## 采购与成本

- Windows 自动补购头目或技能素材前检查公开行情。缺失数据、过期记录、明确零挂牌不作为自动可购来源；性别明确无挂牌时不借用不限性别的低价。用户明确手动报价的采购规格仍可选。
- 优先使用符合约束的库存，采购数量与步骤相同的候选继续比较费用；省钱规划按原新增支出口径。头目家族最低价仍视为 2V 基础参考，不保证指定 V 位、梦特、性格或已配好技能；3V 以上按原规则手动报价。
- 可升级学习的采购来源列出配种前学习步骤，现成遗传技能组合需要明确手动报价。报价快照保留来源家族、性别查询、数量与时间，避免用另一个家族的低价冒充技能素材报价。
- 行情查询只在需要补购时执行，运行在可取消的独立规划进程中，复用十分钟内的缓存；失败时保留手动报价，缺数据不视为免费或有货。库存不上传到行情来源。
