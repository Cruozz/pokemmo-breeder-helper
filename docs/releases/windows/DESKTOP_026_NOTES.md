# 电脑端 V0.2.6：清除规划、路线配色与百变怪转性别优化

- 新增“清除当前规划与路线”，同时清除当前执行、新建议、进度标记与本次禁用；保留目标、真实库存、已完成核销及子代。清除后后台旧结果失效，重启不恢复旧路线。
- 母体主线为蓝色、性格手为紫色、遗传技能为橙色，其他 IV 素材为灰蓝色；整条分支的节点与连线同步配色。文字图例和状态标签区分路线用途与执行进度。
- 预览、真实执行、独立窗口、存档恢复与历史来源展开使用相同分类逻辑，不修改库存或执行存档格式。
- 在所有搜索共用的子代构造入口拦截高档素材与低档百变怪转性别，并校验保留原有效 IV、不降档。覆盖母体转换、直接配对及性格手搜索；正常同档升 V 和不转性别的性格遗传仍可使用。
- 旧执行路线不会自动替换；需要新算法时可清除旧规划后重新生成。

本次为 Windows 桌面版。测试使用合成库存和临时数据库。
