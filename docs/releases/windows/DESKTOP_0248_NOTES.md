# Windows 0.2.48

- 批量识别默认直接入库，标为“未审核”，无需先填写性格、头目、粒子或时装；未审核素材可直接参与规划。
- 识别到什么先保存什么，资料不完整也可入库。规划使用已知资料，不猜测未知性格；名字、性别或仓位对应不确定时，补充必要信息后使用。
- 可按需求在批量结果或库存中补充原记录，保存后保持未审核；也可单独标记已审核，不要求所有资料填满，不设置必须登记的性格名单。
- 补填仅更改相应资料，保留其他已知粒子、时装等信息与保护；不重复入库，不恢复已消耗素材。
- 数量、范围与已有仓位冲突继续拦截。连续识别与批量识别保留独立入口，读取名单后请在游戏点击“否”返回；工具不操作游戏。
- 仅发布 Windows，Android 保持 0.10.0，孵蛋规则保持 0.2.43。使用步骤见仓库 docs/bulk-capture.md。
