# Windows V0.2.16 — 重置目标、删除账号、精简提示

## 清除规划

确认清除后，同时清除路线、新建议、临时禁用素材、目标精灵、性格、遗传技能。
六项个体值恢复 X（任意），成品性别恢复任意，梦特、锁性格、锁性别、百变怪转换、
头目素材等开关关闭；类别恢复普通，策略恢复库存优先与智能锁定。
已核销历史、库存与入库子代保留；取消或存储失败不清空目标。

## 删除账号

在账号排序中选中账号并点击删除，是待保存修改；关闭或取消窗口不执行删除。
保存时列出每个账号的全部素材数量，经再次确认后事务性删除账号和素材，
同步排列顺序。账号名精确匹配，不混淆大小写，也不受库存筛选影响。
账号可全部删除，主账号不会自动重新出现在已保存的账号列表中。
新录入时仍可通过已有“+”入口新增账号；无账号时新建默认账号沿用原录入行为。
删除前先停止连续扫描；规划中的后台计算会失效，不能把已删除素材恢复进旧建议。
删除同时清除当前规划与路线，但保留目标设置。

库存“撤销删除”恢复账号与素材，空账号也可恢复；旧路线不恢复。
新增的 SQLite 删除历史上下文字段兼容原有普通素材删除历史。
仅操作本地库存，不触碰游戏内账号或精灵；测试与 EXE 自检使用独立临时数据。

## 精简界面

移除用户红框中的离线角标、重复查询说明、页脚来源、图片切换说明和空目标提示。
来源、授权声明与基础努力值计算口径保留在发行包文档中。
努力值仍是单只收益乘同种群怪数量，不含加成，不保证点位只出现该种精灵。
普通／闪光点击切换不变；资料快照与图片资源不变。

第三方离线资料的公开再分发授权未核实，先本地交付，不公开发布含该资料的版本。
