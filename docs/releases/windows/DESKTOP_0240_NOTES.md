# Windows 0.2.40 / Android 0.8.0

本次主要更新安卓版库存采集体验。浅色蓝紫界面、紧凑小字浮窗与箭头收放；选择历史／库存账号、填写仓库页格；静态画面复用OCR；完整稳定结果直接入库（待确认），仓位冲突保留草稿并暂停。截图和录屏草稿也能直接入库。
