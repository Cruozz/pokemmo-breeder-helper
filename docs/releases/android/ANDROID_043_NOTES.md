# 安卓版 0.4.3：与电脑端 V0.2.8 孵蛋逻辑同步

- 基于本地安卓 0.4.2 的完整源码继续开发，并补入仓库；保留核销、撤销、原子存档、阶段续接和导图，不退回 GitHub 上的早期安卓界面。
- APK 构建直接打包同一份电脑端 planner、chain_planner、execution、reference_data、route_roles 及离线数据，包含低档百变怪转性别保护、性格手搜索和严格遗传技能规则。
- 选择目标精灵后可勾选最多四个遗传技能；切换目标清除上一个物种的技能选择。后端再次验证技能，阶段续接保留已启用路线的技能目标。
- 新增“清除当前规划与路线”：保留表单目标、真实库存及已核销子代；清除执行、建议、进度和规划禁用记录。正在运行的旧搜索结果作废，重启和撤销库存操作不会恢复已清除路线。
- 母体蓝色、性格手紫色、IV 素材灰蓝色；目标技能叠加橙色双框和并行线，仅沿实际传递路径延续。完成/选中/折叠不改变路线身份。
- 公/锁公浅蓝底色、母/锁母浅粉底色，未知或未锁定性别为灰色；图中文字按实际字体测量换行，单击可查看完整节点信息。步骤清单分别显示父母各自应携带的道具。
- 旧版规则路线保留供查看，执行前需按原目标重新生成并启用建议；不会默默按新规则核销旧路线。

## 安装

Android 8.0+，arm64-v8a / x86_64，versionCode 7。APK 沿用本机原有调试签名，供现有用户测试升级。
安装文件：`PokeMMO-Breeder-Helper-Android-v0.4.3-debug.apk`。

配套 Windows V0.2.9 仅更新版本和发布说明，孵蛋核心逻辑保持 V0.2.8；本批新增功能集中在安卓端。

使用合成素材测试电脑/手机桥接、遗传技能传递、低档百变怪转换、分阶段核销、撤销和清除后恢复。
