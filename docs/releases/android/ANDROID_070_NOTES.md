# Android 0.7.0

- 同步共享规则 0.2.38，支持目标前一档的可选提前性格登记，公母均可。
- 新增系统屏幕共享采集与悬浮窗：拖动、收起、用户名、仓库号、当前格位、每仓格数、自动／手动采集、下一只、暂停、框选范围和停止。
- 稳定完整 IV 画面自动保存为持久化待核对素材，格位按顺序递增；相同画面不重复保存，完全相同的不同精灵可点下一只区分。跳格需更新位置。
- OCR 在本机执行，不录音，不自动点击游戏；识别结果仍须人工核对后进入可规划库存。系统取消共享或应用结束后释放采集资源。
- 屏幕旋转／尺寸变化重新适配，暂停与结束保留已生成草稿。真实游戏识别准确率取决于字体、缩放和详情页内容。
