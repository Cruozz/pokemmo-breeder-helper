# 安卓 0.4.4：精简界面与规划提速

- 移除首页“安卓版 / 桌面规则”版本标语、库存重复导入提醒及表单底部重复说明，缩短加载和高级规则文案。
- 路线颜色说明默认收起，点击“颜色说明”即可查看；保留操作确认、素材核销信息和节点身份。
- 共享规划核心复用同一次搜索的素材筛选和已完成的父本候选，减少重复排序。递归未完成的候选不缓存，避免漏掉后续路线。缓存不跨库存或目标变化复用。
- 无遗传技能的分支跳过空技能集合处理；真实素材去重直接使用素材集合，减少无意义的 ID 排序。搜索宽度、采购优先级及孵蛋规则不变。

## 性能验证

使用合成库存，目标为路卡利欧、5V（特攻不限）、固执、无遗传技能。电脑 Python 3.12 运行 APK 共用的规划核心，优化前后分别启动新进程：

| 库存数量 | 优化前 | 优化后 | 结果 |
| --- | --- | --- | --- |
| 0 | 0.948 秒 | 0.696 秒 | 报告完全一致 |
| 120 | 7.202 秒 | 4.975 秒 | 报告完全一致 |
| 900 | 11.405 秒 | 8.664 秒 | 报告完全一致 |

900 只测试耗时降低约 24%。这些是合成库存的电脑核心测试，不代表用户真实手机的等待时间；真实库存组成、设备性能均会影响速度。可使用 `tools/benchmark_mobile.py` 重现，`--chain-source` 可指定优化前源码进行对照。

在同一 Android 16 x86_64 模拟器上依次安装旧版 0.4.3 和新版 0.4.4 APK，使用相同的 900 只库存测试：旧版 17.272 秒，新版 13.719 秒，耗时降低约 21%。两版均通过与原规划报告的哈希一致性断言。此结果也不是用户真实手机的实测。
