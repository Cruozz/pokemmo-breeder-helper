# 安卓 0.5.0：图鉴界面与库存、孵蛋操作补齐

- 使用精灵图标、红色图鉴主题、青色个体值标记与清晰卡片，适配深浅色、小屏和横屏；编辑页支持系统大字体。
- 素材库存可手动新增、点击编辑，填写种类、性别、性格、个体值、技能、特性、道具、头目、梦特、核对状态、账号、页格和备注；继续支持电脑 JSON 导入与导出。
- 支持搜索、账号/核对状态/头目筛选、全选当前结果、批量确认、批量删除和清空库存。删除与清空需要确认，可从右上角“更多 → 撤销上次操作”恢复。
- “重复检查”沿用电脑端的高置信度重复规则，逐组显示供人工核对，不自动删素材。个体值等关键资料不全时不认定重复。
- 修改或删除正在执行路线依赖的素材会暂停该路线，保留进度并提示重新规划；撤销会一起恢复库存和路线。
- 已启用路线可双击当前可执行节点，标记或取消“孵化中”；节点详情中也有按钮。标记跨重启保存，仅作备忘，不提前核销父母或解锁上层。预览路线不能标记或核销。
- 高级规则补齐“全程锁性格”和中间代性别策略；目标旁可查询离线分布及遗传技能来源。
- 保留未启用预览、本轮禁用与恢复素材、身份双层配色、完成核销、阶段续接、撤销和清除规划。

## 使用

库存页点击“新增素材”录入，点击精灵卡片编辑；导入电脑库存使用“导入 JSON”。右上角“更多”提供导出和撤销。规划生成后先查看路线、筛选本轮素材，再确认启用。

手机录入按用户选择采用电脑库存导入与手动新增；没有加入手机截图 OCR。规划与重复检查复用电脑端规则。

## 安装与验证

`PokeMMO-Breeder-Helper-Android-v0.5.0-debug.apk`，Android 8.0+，arm64-v8a / x86_64，versionCode 10，沿用原调试签名，可覆盖安装。

配套 Windows V0.2.12 更新版本与说明，Windows 孵蛋核心保持 V0.2.10。

验证包含完整 Python 回归、独立桥接检查、Kotlin 单元测试、Android 模拟器测试及实际界面检查；使用合成库存，不操作或上传用户真实库存。Windows 发布包执行实际 EXE 自检。
