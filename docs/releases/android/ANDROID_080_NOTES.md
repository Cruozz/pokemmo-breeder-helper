# Android 0.8.0

- 手机默认浅色蓝紫界面；浮窗主要字号11–12sp，按钮至少44dp，箭头收放，收起后仍可下一只。
- 点选已有或历史用户名，支持新增账号，直接填写仓库页、格位及每页格数。
- 自动识别默认直接入库存（待确认）；截图与录屏草稿也提供一键入库。关掉直接入库可继续使用草稿流程。
- 完全相同画面复用OCR结果，250ms采样、500ms稳定窗口。未知或变动字段仍需稳定，不完整资料不伪造为完整素材。
- 相同仓位的同资料不重复入库；不同素材冲突保留草稿并暂停。
- 后台与界面共享原子库存状态，异步核销拒绝过期库存覆盖，保留撤销。
- 库存页直接导出JSON，沿用电脑格式及全部核对状态；共同孵蛋规则仍为0.2.39。

APK版本码15，包名和签名保持兼容，请覆盖安装。具体操作见[手机库存采集与JSON互通](../../mobile-capture.md)。
