# 手机采集精灵库存

Android 0.6.0 增加截图和录屏导入。入口：**素材图鉴 → 从截图 / 录屏采集库存**。

## 截图录入

1. 在游戏里打开一只精灵的详情页，显示名字、性别和“个体值”一行。文字应清楚，避免弹窗遮挡。
2. 用手机系统截图。回到助手，点“导入截图”，每批最多选 20 张。
3. 等待本机识别，在“待核对”列表点“核对入库”。对照预览图修正名称、六项 IV、性别、性格、特性和技能。
4. 确认头目、梦特及账号、页码、格号。识别不到的 IV 显示 X；不会推算精灵所在格子。
5. 勾选“已核对，可参与规划”，点击“确认入库”。未确认的草稿不会进入库存或参与规划。

## 录屏批量采集

1. 开启手机**系统录屏**，在游戏里手动逐只打开精灵详情和个体值页，每只停留至少 2 秒，切换后等画面稳定。
2. 结束录制。较长录屏先在系统相册中分段剪辑，每段不超过 2 分钟。
3. 回到助手点“导入录屏”。每秒取一帧，按画面出现顺序生成待核对草稿。
4. 连续相同识别结果会折叠，并显示帧数和时间范围。它只能识别“画面相同”，不能判断同属性的精灵是否为同一只；如涉及多只相同属性精灵，使用“复制一只”补足实际数量，再分别核对位置。
5. 对每条草稿核对入库；重复、过场或错误画面可“忽略”。录屏识别结果不会自动覆盖已有库存。

当前版本采用“系统录制 → 导入识别”。尚未实现助手内跨应用实时录制、悬浮框扫描或自动操作游戏。

## 数据与边界

- 中文 OCR 模型随 APK 安装；图片、视频的文字识别和字段解析在本机执行。系统媒体选择器只授予所选文件的读取权限。
- 待核对草稿和预览图保存于应用私有目录，退出页面或重启应用后可继续；媒体草稿不参与系统云备份。入库、忽略或清空后清理不再引用的预览图，原始相册文件不会修改。
- 可随时停止，当前识别任务结束后停止并保留已生成草稿。应用被系统结束时，已保存草稿保留，尚未处理的片段需重新导入。
- 单批 20 张截图或 120 秒录屏；最多保留 200 条待核对草稿。受字体、缩放、主题、遮挡和视频压缩影响，识别结果可能错误或缺失。
- IV 仅接受与“个体值”标签对齐的六项数字，不把能力值、努力值或模糊数字当成 IV。垂直分栏等尚未支持的布局可能需要手动填入；不确定时保留 X。
- 性别图标、头目、梦特和未显示的技能需人工核对。不同详情页不会自动拼接为同一只精灵。
- 草稿可手动复制；已有库存的疑似重复仍由“重复检查”人工处理。不要把折叠帧数当成精灵数量。

本版本用合成截图和录屏检查功能；实际游戏字体、主题和录制质量的识别效果仍需使用者核对。此次开发按要求未进行真机验证。
