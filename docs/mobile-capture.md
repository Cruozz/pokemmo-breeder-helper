# 手机库存采集与 JSON 互通

## 开始采集

在软件库存页面打开实时悬浮采集，授权显示悬浮窗和屏幕共享。点击浮窗的账号仓位按钮选择已有用户名或输入新用户名，填写仓库页、格位、每页格数，然后回到游戏打开精灵个体值页。建议把浮窗放在详情文字以外。

## 展开：手动核对

识别到稳定结果后，显示精灵名、性别、性格及六项个体值；公为蓝色，母为粉色，31 为绿色。未知性别或性格明确显示待确认。

核对无误点“下一只”，当前预览才会保存进库存，仓位推进一格；等新结果出现后再确认下一只。可以先切游戏下一只再点浮窗，也可以先点浮窗再切游戏。当前预览固定，不会被游戏新页面替换。“重识别”放弃当前预览并重新读取；“保存并结束”确认最后一只并关闭采集。“结束采集”直接停止，未确认的预览不入库。

上一只与当前资料完全一致时，继续等待新画面；空白过渡、重复点击、暂停和旋转都不会让旧画面重复入库。两只精灵如果名字、性别、性格、IV 等显示资料完全相同，软件无法仅凭这些画面区分，需在库存中手动添加另一只。

## 最小化：自动采集

点右上角横线最小化为可拖动小按钮。最小化时自动识别、保存到库存，仓位随保存成功推进。若当前已有手动预览，切到自动模式会保存该预览。

每次保存显示小提示，内容和配色与手动预览一致。提示五秒后自动消失，点击游戏立即消失，提示覆盖处也可穿透点击。点小按钮恢复手动模式。暂停状态会保留，可展开后点继续。

所有采集记录保持待确认状态，可回库存修改、批量确认。名称或六项 IV 不完整时等待重新识别；已占仓位出现不同素材时留存冲突草稿并暂停，不覆盖旧库存。跳格时手动修改位置。

## 外观

在软件主界面实时悬浮采集卡片中点“浮窗外观”，调节不透明度和字号。默认主要文字 9–10sp，按字号和系统文字缩放自适应宽高。关闭自适应后可调宽度、高度，内容超出时滚动；浮窗限制在屏幕内。设置实时保存、生效，可一键恢复默认。最小化按钮保持 48dp。自动结果提示为支持触摸穿透，最多 80% 不透明度。

## 截图、录屏和 JSON

截图或已有录屏仍可在采集页面导入、核对、直接入库。库存主页可导出 JSON，通过 Android 系统文件选择器保存，再在 Windows 库存导入；Windows JSON 也可导回手机。两端使用相同库存字段，未核对记录保持未核对。导入是库存合并，不是跨设备自动同步。

本机识别不上传屏幕或库存；此版本只读取授权画面，不代替用户控制游戏。
