# 手机库存采集与 JSON 互通

Android 0.8.0 支持系统屏幕共享悬浮采集、截图和录屏导入。入口：**素材图鉴 → 实时浮窗 / 截图 / 录屏采集库存**。

## 实时浮窗

1. 点击“开启实时采集浮窗”，按系统提示允许悬浮窗并授权屏幕共享。每次启动使用新的授权，可选游戏应用或整个屏幕。
2. 点浮窗中的账号／仓位按钮，像选择天王一样点选已有用户名，也可在下面输入新用户名。填写仓库页、仓库格、每页格数，点“保存”。账号来自已有库存和历史采集设置。
3. 默认开启“自动识别并保存新画面”和“识别后直接入库”。在游戏中打开精灵个体值页，看到浮窗“已入库”后再切换下一只。格位按顺序递增，满页进入下一页；跳格或换账号请先修改位置。
4. 名称与六项 IV 完整且画面稳定时，结果直接进入**素材库存，状态为待确认**，无需回采集列表逐条入库。性别、性格、头目、梦特、技能等仍需核对，确认后才参与规划。缺名称或 IV 时可点“采集当前”保留部分草稿。
5. 同一仓位已有相同资料时不重复增加；已有不同素材时保留待核对草稿并暂停，修改仓位或回库存处理后继续，不覆盖原素材。
6. 手动模式点“采集当前”。同种且六项 IV 完全相同的不同精灵需在游戏切换后手动点“下一只”，以区分两只。不同详情页不会自动合并为一只精灵。
7. 浮窗可拖动；右上角箭头收起／展开，收起后仍保留下一只按钮。用“识别范围”框选清晰的名字、性别和六项 IV，浮窗请放在框外。
8. 可以暂停、继续或结束。关闭“识别后直接入库”可恢复全部存草稿的流程。最多保留 200 条待核对草稿，正式库存不受这个草稿上限约束。

新浮窗使用浅色背景、深蓝文字、蓝紫按钮，主要字号 11–12sp，按钮点击区域至少 44dp。静止画面复用识别结果，250ms 采样、至少 500ms 连续稳定后保存；实际时间受手机性能、画面复杂度及 OCR 初始化影响，以浮窗保存反馈为准。

## 截图与录屏

- 截图：每批最多 20 张，需清楚显示名字和个体值行。
- 系统录屏：每段最长 2 分钟，每只精灵停留至少 2 秒；导入后每秒采样一帧。
- 完成后可选“直接入库”，完整的名称和六项 IV 进入库存并标为待确认；或选“核对入库”，对照原图编辑字段并勾选“已核对，可参与规划”。截图没有可靠仓位时，不猜测页数和格位，请在库存中填写。
- 连续相同录屏帧会折叠，帧数不是精灵数量。如果确实有多只同属性精灵，可用“复制一只”补足数量，再分别填写仓位。
- 过场、空白、重复和错误草稿可忽略；原始相册文件不会被修改。

## 导出给电脑／从电脑导入

1. 结束采集，回到素材库存，点击 **导出 JSON · 手机 / 电脑通用**（右上角“更多 → 导出库存”也可）。在系统文件选择器中保存文件。
2. 将 JSON 传到电脑，在电脑版素材库存使用“导入 JSON”。文件是同一套库存数组格式，不需要转换。
3. 电脑版导出的 JSON 也可通过手机库存的“导入 JSON”载入。手机导入会替换当前库存并清除当前路线，操作前有确认且可撤销；需要保留两份数据时先导出备份。
4. 两端保留编号、账号、仓位、六项 IV（未知为 null）、性别、性格、特性、头目、梦特、技能、备注、来源和核对状态。待确认素材导到电脑后仍待确认，不会因为换平台自动成为已核对素材。

## 识别与数据边界

- 识别在本机执行，只读取授权画面，不录音、不生成整段视频、不自动点击游戏。中文模型随 APK 安装。
- 库存和路线使用原子存档，后台采集与界面共用最新状态。异步孵蛋核销期间库存变化会拒绝旧结果覆盖，提示重试。
- IV 只取与“个体值”标签对齐的六项数字，不把能力值、努力值或模糊数字当作 IV；不确定时保留 X。画面不能证明真实仓位。
- 自动识别可能受游戏字体、主题、遮挡、缩放和视频压缩影响。性别图标、头目、梦特及未显示的技能需要人工核对。
- 草稿和必要预览保存在应用私有目录，重启后可继续；已入库结果可编辑、导出和撤销。更新请覆盖安装，不要卸载或清除数据。
- 本版使用合成素材和隔离模拟器验证；未操作真实游戏。
